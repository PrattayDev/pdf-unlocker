# PDF Unlocker Pro (পাসওয়ার্ড রিমুভার ওয়েব অ্যাপ্লিকেশন)

একটি আধুনিক এবং ব্যবহারকারী-বান্ধব ওয়েব অ্যাপ্লিকেশন, যা পাসওয়ার্ড জানা থাকা যেকোনো সুরক্ষিত PDF ফাইল থেকে পাসওয়ার্ড স্থায়ীভাবে রিমুভ (Unlock) করে সাধারণ PDF হিসেবে ডাউনলোড করতে দেয়। ঠিক যেমনটি **Adobe Acrobat Pro**-তে করা হয়।

🌐 **লাইভ ওয়েবসাইট (Vercel):** [https://pdf-unlocker-six.vercel.app](https://pdf-unlocker-six.vercel.app)  
📦 **GitHub রিপোজিটরি:** [https://github.com/PrattayDev/pdf-unlocker](https://github.com/PrattayDev/pdf-unlocker)

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **স্থায়ী পাসওয়ার্ড রিমুভ:** পাসওয়ার্ড দিয়ে একবার আনলক করার পর নতুন ফাইলে আর কোনো পাসওয়ার্ড থাকে না। ফলে যে কাউকে সরাসরি শেয়ার করা যায়।
2. **১০০% গোপনীয়তা ও নিরাপত্তা (In-Memory Processing):** আপলোড করা কোনো ফাইল কম্পিউটারের ডিস্কে বা সার্ভারে জমা থাকে না। মেমোরিতে (RAM) প্রসেস হয়ে সাথে সাথে ব্যবহারকারীর কাছে ডাউনলোড হয়ে যায়।
3. **আধুনিক UI/UX:** 
   - ড্র্যাগ অ্যান্ড ড্রপ (Drag & Drop) ফাইল আপলোড।
   - পাসওয়ার্ড দেখার/লুকানোর টগল (Show/Hide Password)।
   - স্বয়ংক্রিয় ফাইল সাইজ ও এনক্রিপশন স্ট্যাটাস ডিটেকশন।
   - সঠিক ও ভুল পাসওয়ার্ডের জন্য স্পষ্ট ফিডব্যাক (Bengali & English)।
   - মোবাইল ও ডেস্কটপ সব ডিভাইসে সম্পূর্ণ রেসপনসিভ।

## 🚀 কীভাবে চালাবেন (How to Run Locally)

### অপশন ১: এক ক্লিকে চালু (Windows)
প্রজেক্ট ফোল্ডারে থাকা `start.bat` ফাইলে ডাবল-ক্লিক করুন। এটি স্বয়ংক্রিয়ভাবে সার্ভার রান করে আপনার ব্রাউজারে `http://localhost:5000` ওপেন করবে।

### অপশন ২: টার্মিনাল/কমান্ড প্রম্পট দিয়ে
১. ডিপেনডেন্সি ইন্সটল করুন:
```bash
pip install -r requirements.txt
```

২. সার্ভার চালু করুন:
```bash
python app.py
```

৩. ব্রাউজারে প্রবেশ করুন:
[http://localhost:5000](http://localhost:5000)

## 🌐 ইন্টারনেটে ফ্রি হোস্ট করার নিয়ম (Deploy to Web)
যদি এই ওয়েবসাইটটি ইন্টারনেটে লাইভ করতে চান যাতে সবাই ব্যবহার করতে পারে:
1. কোডগুলো আপনার GitHub রিপোজিটরিতে পুশ করুন।
2. **Render.com** অথবা **Railway.app**-এ গিয়ে "New Web Service" সিলেক্ট করে গিটহাব লিঙ্ক করুন।
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python app.py` (অথবা `gunicorn app:app`)
5. ব্যস! একটি ফ্রি লাইভ ডোমেইন পেয়ে যাবেন।
